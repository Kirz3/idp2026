# Signal Analyser App
``Software requirements``\n
This app reads data from files and converts it to a line plot graph with peak detection and tumor size measurement.

``How to run the program``\n
1. Tranfer the project files to your computer in a way of your choosing.
2. Install Python to your machine if not already installed, install matplotlib, numpy, Pyside6 and Scipy as dependencies to the project.
3. Run src\signal_app\signal_app_main_window.py with Python.
