# Signal Analyser App
``Software requirements``
This app reads data from files and converts it to a line plot graph with peak detection and tumor size measurement.

``How to run the program``
Tranfer the project files to your computer in a way of your choosing. Install Python to your machine if not already installed, install matplotlib, numpy, Pyside6 and Scipy as dependencies.
Run src\signal_app\signal_app_main_window.py
